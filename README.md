# 😄 Short Simple Programs

Small Python programs I wrote while learning. Each folder has its own README.

| Folder | Program |
|---|---|
| **Calculator** | A menu-based calculator for basic operations, squares and square roots, plus a quadratic equation solver |
| **Encryption** | Encrypts a word by shifting each letter a set number of places (a Caesar cipher) |
| **Statistics** | Calculates median, mode, mean, range, interquartile range, standard deviation and coefficient of variation |
| **Number Rearranger** | Reverses the digits of a number (e.g. 12345 → 54321) |

## How to Run

You need Python 3. Run a file from its folder, for example:

```bash
python "Calculator/Advanced_Calculator.py"
```

The Statistics program also needs NumPy (`pip install numpy`).
