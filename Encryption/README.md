This is a simple compact code which can encrypt data based on user inputted data and by how many indexes to increment each value.
The code is simple and took 5 minutes.
Have fun running it. 😄

**Example:** `Hello World xyz!` with a key of 3 becomes `Khoor Zruog abc!`
- Letters wrap around after z (so x → a)
- Capital letters stay capital
- Spaces, numbers and symbols are left as they are
