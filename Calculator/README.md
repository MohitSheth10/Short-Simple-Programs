# 🧮 Advanced Calculator

A text-menu calculator with two modes.

## Option 1: Calculation
- Addition, subtraction, multiplication, division
- Square and square root
- Stops division by zero and square roots of negative numbers, and asks for a new number instead
- Rounds decimal answers to 2 places

## Option 2: Quadratic Solver
- Enter a, b and c for 0 = ax² + bx + c
- Shows the equation and its factored form, e.g. `0 = x²-3x+2` → `0= (x-2)(x-1)`
- Asks for new values if a = 0 (not a quadratic) or if b² − 4ac < 0 (no real solutions)

## Option 3: Exit

## How to Run
```bash
python Advanced_Calculator.py
```
No extra libraries needed. It only uses Python's built-in `math` module.
